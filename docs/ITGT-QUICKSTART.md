# I-TGT — your first GPS release in one minute

1. Select a compatible guided bomb or missile. Check the [compatibility table](GPS-WEAPONS.md).
2. Press **F6**, or your chosen key from **Settings → I-TGT GPS SETTINGS**.
3. Click the map to create **T01**, or select a Data Link target and press **DL→GPS** to copy its known position.
4. Leave **SCOPE = CYCLE** (default). Press **ARM / GPS** and check **NEXT GPS T01**. Successful releases cycle through all marks in order: with six marks, ten weapons use T01–T06, then T01–T04. **BIND** in CYCLE resets the queue to the first mark.
5. Close I-TGT with the same key. GPS stays armed. In cockpit view, the HUD diamond shows the point; small text shows range, bearing and an approximate bomb delivery cue. Both are hidden in external views.
6. Approach the point, check native weapon safeties and use the normal weapon trigger. **RELEASE WINDOW ~** is an estimate, not an impact guarantee.

**DISARM** restores native targeting. Changing the selected mark after release does not redirect weapons already in flight.

Guided cluster dispensers need a real visible enemy surface target near the mark. Locust and Lawn Chair are unguided and cannot use GPS. Laser terminal guidance needs illumination.

For all controls and multi-target assignments, read the [detailed planning guide](ITGT-GUIDE.md).
