# I-TGT GPS — функції та планування місії

Для першого запуску є [короткий гайд](ITGT-QUICKSTART.uk.md). Цей документ пояснює всі органи керування й підготовку кількох призначень.

## Відкрити екран

Натисни **F6**. Якщо потрібна інша клавіша, відкрий **Settings**, знайди панель **I-TGT GPS SETTINGS**, натисни поточний бінд і потрібну клавішу. **Esc** скасовує зміну. Новий бінд зберігається автоматично. У цій же панелі можна вимкнути топографічний фон штатної карти.

Коли I-TGT закритий, постійної кнопки на екрані немає. Повторне натискання бі́нда закриває I-TGT, але не вимикає вже озброєний GPS.

## Поставити мітку

- Натисни лівою кнопкою на карті: з'явиться T01. Можна створити до **16 міток**.
- Або вибери ціль у Data Link і натисни **DL→GPS**. З першої вибраної цілі копіюється відома позиція. Якщо немає відомих координат, екран повідомить про це.
- **PREV / NEXT** перемикають мітки, **DEL** видаляє вибрану. Після видалення всіх міток нумерація знову починається з T01.

GPS-мітка зберігає координати в момент створення. Рухома ціль може поїхати звідти; DL→GPS не створює постійного стеження за нею.

## Призначити зброї

1. Вибери зброю штатними кнопками гри або **WPN** на I-TGT.
2. Вибери потрібну мітку через **PREV / NEXT**.
3. Через **SCOPE** вибери рівень призначення:
   - **TYPE** — усьому вибраному типу зброї;
   - **PYLON** — конкретному пілону;
   - **STORE** — одній бомбі або ракеті.
4. Для PYLON або STORE кнопкою **SLOT** вибери потрібне місце. Угорі видно номер пілона та боєприпасу.
5. Натисни **BIND**. Для інших міток або пілонів повтори ці дії.
6. Натисни **ARM / GPS** для ввімкнення GPS. Ця кнопка також призначає активну мітку поточному вибраному рівню — перевір його перед натисканням.

Окремий STORE має пріоритет над PYLON, а PYLON — над TYPE. **NEXT GPS Txx** показує мітку наступного боєприпасу в штатному порядку скидання. SLOT не переставляє чергу скидання. Якщо наступний сумісний боєприпас не має призначення, GPS утримує запуск: признач йому мітку або натисни **DISARM**.

## Зайти на ціль і скинути

Закрий I-TGT, перевір штатні запобіжники й зайди на позначку. На HUD є ромб GPS-цілі, відстань і курс; якщо точка поза екраном, позначка буде біля його краю. Білий кінчик значка літака на GPS-карті показує ніс.

Дрібні підказки над HUD допомагають оцінити захід:

| Підказка | Що робити |
| --- | --- |
| TURN LEFT / RIGHT | Повернути в бік мітки |
| CLIMB / TOO LOW | Набрати висоту |
| TOO FAR / HOLD | Продовжити зближення |
| RELEASE WINDOW ~ | Приблизне вікно скидання |

Оцінка враховує поточну висоту, швидкість і параметри зброї. Вона приблизна: не прогнозує вітер або перешкоди на траєкторії й не гарантує влучання. Звичайна кнопка вогню запускає зброю; в польоті боєприпас зберігає координату, навіть якщо змінити активну мітку.

Керованій касетній бомбі для штатного розкриття потрібна **реальна видима ворожа наземна/морська ціль біля мітки**. Порожня точка не стає об'єктом цілі. Locust і Lawn Chair — некеровані мінні касети: їх скидають через CCIP, GPS для них не вмикається. Лазерній бомбі для лазерного кінцевого наведення потрібне підсвічування.

## Керувати картою

Коліщатко або **+ / −** змінюють масштаб. Права кнопка з перетягуванням переміщує карту. **OWN** центрує на літаку, **TGT** — на мітці. Заголовок вікна дозволяє його пересувати, нижній правий кут — змінювати розмір. Над вікном команди огляду й zoom камери блокуються; після виходу курсора повертаються.

**TOPO** перемикає топографічний фон штатної карти. GPS-карта зберігає свій рельєф. При переході в іншу місію рельєф генерується заново; зміна літака або місії очищає мітки й призначення.

GPS-запуск доступний в одиночній грі або хосту. [Таблиця сумісності встановленої зброї](GPS-WEAPONS.md) показує підтримку адаптером; це не підтверджений польотний тест кожного рядка.

## Спланувати кілька призначень

Наприклад, у місії є три відомі нерухомі цілі. Хочеш використати один тип керованої зброї, але відправити різні боєприпаси до різних точок.

1. Створи **T01, T02, T03** вручну або через Data Link. Зістав координати й висоту міток із картою. Імпорт — це відома HQ позиція, яка може бути застарілою; повторний DL→GPS створює нову мітку, не оновлює стару.
2. Вибери зброю. На **TYPE** признач T01 як загальне призначення через BIND.
3. Перемкни **SCOPE → PYLON**, через SLOT знайди потрібний пілон, вибери T02 і натисни BIND. Боєприпаси цього пілона використовуватимуть T02 замість загальної T01.
4. Перемкни **SCOPE → STORE**, знайди конкретний боєприпас на цьому пілоні, вибери T03 і натисни BIND. Тільки він матиме T03, решта цього пілона — T02.
5. Перед ARM перевір активну мітку, SCOPE і SLOT: ARM також виконує BIND для поточного вибору. Щоб не змінити вже підготовлену схему, залиш їх на щойно збереженому призначенні.
6. Увімкни GPS й перевір **NEXT GPS**. Гра сама визначає наступний боєприпас; SLOT лише вибирає, кому призначити координати, а не кого скинути наступним.
7. Після кожного запуску перевір наступне призначення. Інший активний номер мітки в редакторі не обов'язково є координатою наступної зброї: вирішальне поле — NEXT GPS.

| Для боєприпасу є призначення | Яка точка використовується |
| --- | --- |
| STORE, PYLON і TYPE | STORE |
| PYLON і TYPE | PYLON |
| Тільки TYPE | TYPE |
| Жодного, GPS увімкнений | Запуск сумісного боєприпасу утримується |

STORE споживається під час запуску: індивідуальне призначення не переноситься автоматично на новий боєприпас після перезарядження. TYPE і PYLON зберігаються в межах поточного літака/місії. Видалення мітки прибирає всі призначення, які посилались на неї. Під час зміни літака або місії схема очищається; збереження плану у файл поки немає.

## Довідник кнопок

| Кнопка | Дія |
| --- | --- |
| WPN | Наступна штатна станція/тип зброї |
| + / − | Масштаб GPS-карти |
| OWN / TGT | Центрування на літаку / активній мітці |
| TOPO | Топографічний фон штатної карти ON/OFF |
| SCOPE | TYPE → PYLON → STORE |
| SLOT | Наступний доступний боєприпас для призначення |
| DL→GPS | Нова мітка з першої вибраної цілі Data Link |
| PREV / NEXT | Попередня / наступна GPS-мітка |
| DEL | Видалення активної мітки та її призначень |
| BIND | Збереження призначення на вибраному рівні |
| GPS або ARM / DISARM | Увімкнення з BIND / вимкнення GPS |
| X або клавіша відкриття | Закриття MFD без вимкнення GPS |

## HUD і його шар

Яскравий ромб із центральною точкою позначає GPS-координату в світі. Коли вона поза екраном, символ стоїть біля краю й показує напрямок. Під ним — номер і відстань. Amber-позначка використовується для попереднього перегляду/підказок, зелена — для приблизного вікна скидання.

Поки GPS вимкнений, HUD показує активну мітку як **PREVIEW**. Коли ввімкнений — призначення наступного боєприпасу. Якщо воно відсутнє, HUD не вигадує ціль із вибраної мітки: перевір NEXT GPS і BIND.

Символіка польоту поступається шару меню: вона ховається при відкритті I-TGT, карти, чату або інших екранів із системним курсором. Закрий їх для повернення позначки. Текст має тонкий темний контур для читабельності без фонової панелі.

## Якщо щось не працює

| Ситуація | Перевірка |
| --- | --- |
| DL→GPS не створює мітку | Чи вибрана ціль; чи HQ має її відому позицію; чи не створено вже 16 міток |
| Зброя не підтримується | Дивись seeker/умову в таблиці; назва «керована» сама по собі не означає підтримку адаптера |
| GPS не дає запустити | NEXT GPS, призначення, боєзапас, штатні запобіжники; чи ти хост |
| Касета долетіла, але не розкрилась | Чи є реальна допустима ворожа ціль біля точки, чи видима вона носію |
| Рухома ціль пішла з мітки | Координата зберігається як знімок; імпортуй нову позицію і перепризнач невипущену зброю |
| Змінилась місія або літак | Створи мітки й призначення заново |
| Потрібне штатне наведення/залп | Натисни DISARM |

Тестовий реліз підтверджує збірку та перевірені шляхи запуску. Він не означає однакову точність усіх модових префабів: дальність, фізика, термінальне наведення й розкриття залежать від конкретної зброї.
