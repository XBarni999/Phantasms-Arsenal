# I-TGT — перший GPS-запуск за хвилину

1. Вибери сумісну керовану бомбу або ракету. [Таблиця сумісності](GPS-WEAPONS.md) показує підтримку адаптера.
2. Натисни **F6**. Інший бінд можна вибрати в **Settings → I-TGT GPS SETTINGS**.
3. Клікни по карті, щоб створити **T01**. Або вибери ціль у Data Link і натисни **DL→GPS**: скопіюється її відома позиція.
4. Для простого першого запуску залиш **SCOPE = TYPE**. Натисни **BIND**, потім **ARM / GPS**. Перевір угорі **NEXT GPS T01**.
5. Закрий I-TGT тією ж клавішею. GPS залишиться ввімкненим. Ромб на HUD покаже точку; невеликий текст — відстань, курс і приблизну підказку для бомби.
6. Зайди на ціль, перевір штатні запобіжники й використай звичайну кнопку вогню. **RELEASE WINDOW ~** — приблизна оцінка, а не гарантія влучання.

**DISARM** повертає штатне наведення. Перемикання мітки після запуску не змінює координати вже випущеної зброї.

Для керованої касети біля точки потрібна реальна видима ворожа наземна/морська ціль. Locust і Lawn Chair некеровані — GPS для них недоступний. Лазерне кінцеве наведення потребує підсвічування.

Усі кнопки, кілька цілей, призначення пілонів та окремих боєприпасів: [детальний гайд](ITGT-GUIDE.uk.md).
